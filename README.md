# 🧶 Sweaters Website

A modern and visually focused **sweaters fashion website** built with HTML and CSS. The project focuses on creating a clean, minimal, and stylish product presentation with a strong visual layout.

## ✨ Features

* 🧥 Modern sweater-focused landing page
* 🖤 Black background with wheat-colored typography
* 🖼️ Multiple product images arranged in a layered layout
* 🧭 Simple navigation menu
* 📦 Product information section
* 🔗 Collection and navigation links
* 🎨 Minimal fashion-oriented visual design
* 💻 Clean and simple frontend implementation

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Git & GitHub**
* **VS Code**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/bhavishyavashishtgit/sweaters-website.git
```

### 2. Open the project

```bash
cd sweaters-website
```

### 3. Run the website

Open `index.html` directly in your browser, or use the **Live Server** extension in VS Code.

## 🎨 Design

The website uses a minimal fashion-inspired visual style with:

* Black background
* Wheat-colored text
* Large typography
* Product-focused imagery
* Simple navigation
* Layered image positioning

The goal is to keep the interface visually strong without unnecessary UI elements.
